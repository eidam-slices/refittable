# refittable

Nástroj pro úpravu a export rozvrhů ze Sirius API (**FIT ČVUT**).

Umožňuje nahrazovat či mazat vybrané paralelky předmětů a vkládat vlastní události (např. tělocvik, který se standardně nezobrazuje v rozvrhu) s ohledem na státní svátky.

Přihlašovací údaje i veškerá pravidla úprav se definují v jednoduchém konfiguračním souboru s pravidly (`rules.toml`).
